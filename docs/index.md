# Snapper iOS

Native iOS client for the [Snapper](https://github.com/mateusz-klatt/snapper) trading platform — a SwiftUI app that lets you run trading actions from a phone against a self-hosted Snapper backend.

## Links

- [Source code on GitHub](https://github.com/mateusz-klatt/snapper-ios)

- [Security disclosure policy](https://github.com/mateusz-klatt/snapper-ios/blob/master/SECURITY.md)

## What it is

Snapper iOS is a thin client. Your account, orders, positions, alerts, and balances all live on the backend you run yourself; the app just renders them and lets you submit trade commands. The app does not run any analytics, ad, or telemetry SDK — see the [privacy policy](privacy-policy) for details.

The maintainer ships builds to the Apple App Store. The source is open under MIT and forks build for the simulator out of the box — see the [GitHub repo](https://github.com/mateusz-klatt/snapper-ios) for build instructions.
