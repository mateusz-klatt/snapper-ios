# Multi-pattern lint for ios-i18n-check (v2 — Phase H).
# Each non-comment line is one ripgrep pattern executed against
# ios/Snapper/Views, ios/Snapper/Views/Components, ios/Snapper/ViewModels.
# Patterns target user-visible string literals that must be routed
# through the catalog. Hits are filtered against check_i18n_allowlist.txt.

# v1 LOCKED — bare String(localized:) doesn't switch lookup on iOS 26.2
String\(localized:\s*"[^"\\]+"

# Modifier-based string APIs (single-line typical).
\.navigationTitle\(\s*"[^"\\]+"
\.navigationBarTitle\(\s*"[^"\\]+"
\.alert\(\s*"[^"\\]+"
\.confirmationDialog\(\s*"[^"\\]+"

# Kwarg-position-independent (catch text: first, prompt: second).
\.searchable\([^)]*?prompt:\s*"[^"\\]+"
\.alert\([^)]*?title:\s*"[^"\\]+"

# Format-string templates producing user-facing strings.
Text\(\s*String\(\s*format:\s*"[^"\\]+"
