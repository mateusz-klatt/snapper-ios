# Allowlist for the v2 multi-pattern lint (check_i18n_strict.sh).
#
# Each non-comment, non-blank line is `<path>:<line>:<reason>`. A hit
# whose <path>:<line> prefix matches an entry here is ignored.
#
# Two categories of allowed hits remain:
#   1. "phase-d formatter follow-up — <fragment>" — String(format:)
#      hits that need locale-aware NumberFormatter / DateFormatter
#      via the LocaleFormatters helper. Phase D is the planned PR
#      that wires these through.
#   2. "numeric placeholder — locale-neutral" — single-token numeric
#      hints in TextField placeholders ("0.0", "1.5"). Decimal
#      separator semantics come from the keyboard input parser, not
#      the placeholder string, so translating them adds no value.
#
# The v1 single-pattern lint (check_i18n.sh) still guards against the
# most dangerous `String(localized: "...")` pattern via the simpler
# check_i18n_allowlist.txt format.
